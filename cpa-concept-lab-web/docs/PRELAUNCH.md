- [ ] 처리방침·약관에 적은 운영 약속을 지킬 수 있는지: 변경 7일(불리 30일) 전 공지, 서비스 종료 30일 전 공지, 삭제 데이터 별도 보관 안 함, 만 14세 미만 정보 발견 시 삭제
- [ ] Netlify 접속기록 보관기간(Netlify 정책)과 Firebase Auth IP 처리 — 처리방침에 “업체 정책에 따름”으로 적음
- [ ] 이용약관은 초안. 유료 이용권 도입 시 4~6절(결제·구매 복원·환불) 확정 후 개정, 필요하면 법률 검토
- [ ] 유료 이용권(하루 100문제 무료 / 19,900원 영구 이용권)은 **예정·미확정**으로만 표시. 도입하면 Android 앱 안 개인정보 처리방침의 “유료 결제·인앱 구매 없음” 문구와 Play 등록정보(무료·인앱 구매 없음), 데이터 보안 양식도 함께 고쳐야 함

## Google Play 데이터 보안 양식과의 관계
- 데이터 보안 양식은 **Android 앱**이 수집하는 데이터를 신고합니다. 앱은 인터넷 권한이 없고 데이터를 수집하지 않으므로 “수집 없음”이 맞습니다.
- 홈페이지 고객지원 로그인(Firebase)은 앱 밖의 웹 서비스이며, 처리방침에 별도로 적었습니다. 앱 안에서 홈페이지 로그인으로 연결하는 기능을 넣으면 신고 내용을 다시 검토하세요.
- 계정 삭제 URL 요구: 앱에는 계정이 없으므로 해당 없음. 웹 계정 삭제 방법은 `/data-deletion` 에 안내.

## 이 환경에서 검증하지 못한 것
- 실제 Firebase 프로젝트로의 로그인·저장(프로젝트 미설정 상태), 실제 Google 로그인 팝업(이 환경은 apis.google.com 접속 차단)
- Netlify 실제 배포와 공개 URL 접속
- 실제 휴대폰 브라우저(iOS Safari, 삼성 인터넷)에서의 팝업/리다이렉트 로그인
