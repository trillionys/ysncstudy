# CPA Concept Lab 개인정보 처리방침 (초안)

> 앱 1.0.7 실제 구현 기준으로 작성했다. 앱 내 '설정 → 앱 정보 → 개인정보 처리방침' 화면(`PrivacyPolicy` 객체)과 내용이 같다.
> **공개 출시 전 반드시 채울 항목**: 운영자(개발자) 이름, 개인정보 문의 이메일, 외부에서 접근 가능한 게시 URL(예: GitHub Pages).
> 운영자 정보는 임의로 만들지 않았다.

시행일: 2026-11-25

## 1. 앱과 운영자
- 앱 이름: CPA Concept Lab
- 운영자(개발자): **설정 필요**
- 개인정보 문의처: **설정 필요**

## 2. 수집하는 정보
이 앱은 회원가입·로그인이 없고 이름·연락처·기기 식별자·위치 등 개인정보를 수집하지 않는다.
앱 매니페스트에 인터넷 권한을 포함하지 않으며(검증: `AndroidManifest.xml` 에 `uses-permission` 없음), 분석도구·광고·크래시 수집 SDK를 포함하지 않는다(검증: `app/build.gradle.kts` 의존성 — AndroidX·Compose·Room·DataStore·kotlinx 만 사용).

## 3. 기기에 저장되는 정보
학습기록(풀이 결과·오답노트·복습 일정·개념 진도·메모·북마크)과 설정은 기기 안의 앱 전용 저장공간(Room DB `cpa_concept_lab.db`, DataStore)에만 저장된다. 개발자는 접근할 수 없다.

## 4. 백업
- 앱 내 백업: 사용자가 Android 파일 선택기로 직접 고른 위치에 JSON 파일로 저장한다.
- Android 자동 백업: `android:allowBackup="true"` 와 `data_extraction_rules.xml` 에 따라, 사용자의 기기 설정에서 백업이 켜져 있으면 Android가 학습기록 DB·설정을 **사용자 본인의 Google 계정 백업**에 저장할 수 있다. 이는 Google의 Android 백업 서비스가 처리하며 개발자 서버로 전송되지 않는다.

## 5. 오류 신고
사용자가 '보내기'를 누르면 Android 공유 화면이 열리고, 사용자가 고른 앱(메일·메신저 등)으로만 전달된다. 앱이 자동으로 전송하지 않는다. 포함 정보: 개념·문항 ID, 개념명, 오류 유형, 콘텐츠·앱 버전, 사용자가 쓴 내용. 학습기록은 포함하지 않는다.

## 6. 제3자 제공·공유
개인정보를 수집하지 않으므로 제3자에게 제공·공유하지 않는다.

## 7. 보유기간과 삭제
기기에 보관되며 사용자가 '설정 → 학습기록 관리 → 학습데이터 삭제'(2단계 확인) 또는 앱 삭제로 지울 수 있다. 계정이 없으므로 계정 삭제 절차는 해당 없다.

## 8. 보안
Android 앱 샌드박스 저장공간을 사용한다. 내보낸 백업 파일은 사용자가 보관 위치를 관리해야 한다.

## 9. 변경
변경 시 앱 업데이트와 함께 게시한다. 향후 클라우드 동기화·로그인을 추가하면 수집 항목과 동의 절차를 별도로 다시 작성해야 한다.
