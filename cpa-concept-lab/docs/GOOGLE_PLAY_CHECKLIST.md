# Google Play 출시 준비 체크리스트 (앱 1.0.7 기준, 2026-11-25)

이번 업데이트는 출시 자체가 아니라 출시 가능한 구조를 준비한 것이다. ✅ 완료 · ⬜ 출시 전 필요 · ⚠️ 확인 필요

## 1. 빌드·서명
| 항목 | 상태 | 비고 |
|---|---|---|
| Debug APK | ✅ | 공유 디버그 키(SHA-256 fa7d77c6…fce8) — 기존 설치본 위에 업데이트 가능 |
| Release APK | ✅(업로드 키 서명) | `./gradlew assembleRelease` → `app-release.apk` (R8 축소, 약 3.7MB) |
| Release AAB | ✅(업로드 키 서명) | `./gradlew bundleRelease` → `dist/CPAConceptLab-1.0.8-release.aab` (약 6.1MB) |
| 업로드 키 | ✅ | `upload-keystore.jks`(PKCS12 RSA 4096, alias `upload`, 2054년까지) 생성 — Git 에 없음, 개발자가 별도 보관. SHA-256 `F2:73:78:57:…:85:01:A6`. `keystore.properties`(커밋 금지)로 자동 서명. **Play App Signing 사용** |
| 디버그 설치본 → Play 설치본 | ⚠️ | 서명 키가 달라 같은 기기에서 덮어쓰기 설치가 안 된다. 사용자에게 '앱 내 전체 백업 → 삭제 → Play 설치 → 복원' 절차 안내 필요 |
| 키스토어·비밀번호 커밋 | ✅ 없음 | |

## 2. targetSdk (Play 정책)
| 항목 | 상태 | 비고 |
|---|---|---|
| compileSdk / targetSdk | ✅ 36 | 이 세션에서 SDK Platform 36 을 설치해 빌드. 2026년 11월 기준 신규 앱·업데이트 요구 수준(API 36)에 맞춤. **출시 시점에 Play Console 공식 공지로 재확인** |
| AGP 버전 | ⚠️ | AGP 8.7.3 + compileSdk 36 으로 빌드·테스트 통과. AGP 최신 버전으로의 업그레이드는 별도 점검 권장 |
| Edge-to-edge | ✅ | `enableEdgeToEdge()` + Scaffold 패딩. API 35+ 강제 적용과 같은 동작 |
| 화면 방향 | ⚠️ | 매니페스트 `screenOrientation="portrait"`. API 36 에서는 큰 화면(sw600dp 이상)에서 방향·크기 제한이 무시된다 → 태블릿 가로 화면 실기기 확인 필요 |
| 키보드(adjustResize·imePadding)·글자 크기(앱 내 85~150%) | ✅ 코드 | 실기기 확인 필요 |
| 예측 뒤로가기 | ⚠️ | Navigation Compose 기본 동작. 실기기 확인 필요 |

## 3. 개인정보·Data Safety (실제 구현 점검 결과)
| 질문 | 답 | 근거 |
|---|---|---|
| 데이터 수집 | 수집 안 함 | 인터넷 권한 없음, 네트워크 코드·SDK 없음 |
| 데이터 공유 | 공유 안 함 | 〃 |
| 분석·광고·크래시 SDK | 없음 | 의존성: AndroidX·Compose·Room·DataStore·kotlinx·Navigation |
| 외부 서비스 | 없음(공식 출처 링크는 브라우저로 열기만 함) | `ContentNotice.open` = ACTION_VIEW |
| 오류 신고 | 사용자가 고른 앱으로 공유(ACTION_SEND) — 앱이 전송하지 않음 | `ShareErrorReporter` |
| 저장 | 기기 내부(Room·DataStore) | |
| Android 자동 백업 | 사용자 Google 계정 백업(개발자 미수신) | Play 지침상 개발자 '수집'에 해당하지 않음 — 방침에 명시 |
| 사용자 삭제 | 가능 | 설정 → 학습기록 관리 → 학습데이터 삭제(2단계 확인) |
| 계정 삭제 요구사항 | 해당 없음 | 로그인·계정 없음 |
| 개인정보 처리방침 | 앱 내 화면 ✅ / 외부 URL ⬜ | `docs/PRIVACY_POLICY.md` 를 공개 URL 로 게시하고 운영자·문의처 채우기 |

## 6. 배포 절차(권장)
자세한 단계·폼 답변·스토어 그래픽: [`play-store/UPLOAD_GUIDE.md`](../play-store/UPLOAD_GUIDE.md)
1. `keystore.properties` 준비 → `./gradlew bundleRelease`
2. Play Console 앱 생성 → Play App Signing 등록 → **내부 테스트** 트랙 업로드(최대 100명)
3. 실기기 점검(위 ⚠️ 항목) → **비공개 테스트**(개인 개발자 계정은 공개 전 비공개 테스트 요건이 있을 수 있으니 Play Console 안내 확인)
4. 스토어 등록정보: 앱이 공식 앱이 아님을 설명에 명시, 개인정보 처리방침 URL, Data Safety(위 3절), 콘텐츠 등급 설문
5. 프로덕션 출시
